Wireframe annotations (for reviewers)

  • Every input has a <label for>; helper text and error text are both referenced by aria-describedby (hint first, error second).
  • Errors use text (“Error:” prefix), a thicker border and colour — never colour alone (SC 1.4.1, 3.3.1).
  • Error-summary links jump to the field; in React focus moves to the summary on failed submit and an aria-live region announces field-level changes on blur.
  • autocomplete tokens (name, email) satisfy SC 1.3.5 Identify Input Purpose.
  • Radio group and checkbox are wrapped in fieldset/legend; all targets are at least 44px high.
  • On success React opens a confirmation dialog, traps focus inside it until Escape/Close, then returns focus to the trigger.
