Wireframe annotations (for reviewers)

  • Landmarks: header (banner), nav “Primary”, main, 3 sections, aside (complementary), footer (contentinfo) with a “Contact the library” heading. One <h1>; headings never skip a level.
  • Skip link is the first tab stop; it moves focus to <main tabindex="-1">.
  • Search is a native GET form with a visible label and hint wired by aria-describedby — no JS required.
  • Card links are the heading text only (no nested interactive controls inside a link), so each card is one tab stop with a meaningful name.
  • Placeholder images are aria-hidden: in the build they become decorative or receive real alt text.
