# Primary Assistive Technology Persona

## Thandiwe Mokoena

**38 · Call-centre team leader, studying part-time for a bookkeeping certificate**

Thandiwe has been blind since the age of 24. She has no usable vision and uses the web by listening to a screen reader and by keyboard only.

## Technical configuration and assistive tools

| | |
|---|---|
| **Computer** | Windows 11 laptop with the **NVDA** screen reader, using Firefox and Chrome |
| **Phone** | iPhone with the built-in **VoiceOver** screen reader |
| **Braille display** | Used to check the spelling of email addresses and reference numbers |

## How she uses the web (input modalities)

- **Keyboard only** on her laptop, no mouse.
- Uses **Tab** and **Shift+Tab** to move between links, buttons and form fields.
- Uses NVDA shortcuts to jump around a page: **H** for headings, **D** for landmarks and **F** for form fields.
- On her iPhone, uses touch gestures with VoiceOver.

## Pain points with conventional web design

| Problem | What happens to her | What the hub does about it |
|---|---|---|
| No headings or landmarks | She has to listen to the whole page line by line | Clear headings and page landmarks |
| Form fields without labels | NVDA says "edit, blank" and she has to guess | Every field has a visible label and a hint |
| Errors shown only in red | Nothing seems to happen when she submits | Errors are written in text, announced, and focus moves to a list of errors |
| Filters that change silently | She doesn't know whether the list changed | The number of results is read out |
| Pop-ups that don't move focus | She stays stuck on the page behind the pop-up | Focus moves into the pop-up and back out when it closes |
| Pages that change without saying so | She thinks the link didn't work | Focus moves to the new page's heading |

## Primary goals

1. Book a session in the Assistive Technology Suite without phoning the library.
2. Register for a course and get a confirmation number she can read on her braille display.
3. Find audiobooks in an accessible format in the digital archive.
4. Check her bookings and cancel one if her plans change.
